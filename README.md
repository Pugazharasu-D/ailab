# Exploration in Artificial Intelligence Lab

This repository contains all 13 Python lab exercises from the uploaded EAI lab manual and the six CSV datasets supplied for Experiments 8–13.

## Contents

- `experiment_1.py` through `experiment_13.py`
- `experiment_8_student_performance.csv` through `experiment_13_study_materials.csv`

## Running

```bash
pip install numpy pandas matplotlib
python experiment_8.py
```

Run from the repository root so the CSV paths resolve. Colab-specific upload prompts were omitted for local execution. Exercises 10–13 demonstrate rule-based or template-based methods and do not call a live AI API.
